> **الحالة: قيد البناء — لا يوجد كود بعد.** المتوفر حاليًا ملفات الأساس (الوثائق والقواعد) فقط، وهي بانتظار موافقة المالك.
> **Status: under construction — no code yet.** Only foundation docs exist, pending owner approval.

## الفكرة
**BAKI** مدير تنزيلات لنظام **ويندوز**، يسرّع التنزيل بتقسيم الملف إلى أجزاء، ويستأنف التنزيل المقطوع، ويلتقط الروابط من المتصفح. واجهته **عربية أولًا** ويمكن تحويلها إلى الإنجليزية بضغطة زر.

يُبنى كبديل مفتوح المصدر لبرامج مثل Internet Download Manager، اعتمادًا على ما نُشر عنها من وصف لمزاياها فقط (موقعها ووثائقها). **لا ننقل منها كودًا ولا تصميمًا ولا اسمًا**، ولا نفكّ ملفاتها.

## الهدف
- تنزيل حقيقي وموثوق، وكل رقم نعرضه نقيسه فعلًا.
- واجهة عربية سليمة (من اليمين لليسار) وإنجليزية كاملة.
- أمان من أول يوم، واختبارات لكل ميزة.
